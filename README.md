# 🛒 Sistema de Gestión - Supermercado en C++

Este es mi segundo proyecto en C++. Es un sistema para un supermercado que maneja productos y el stock de 4 depósitos.

### 📋 Que hace el programa:
1. 📦 Cargar Productos: guarda nombre y precio en una struct.
2. 🏬 Cargar Stock: carga las cantidades en una matriz de 4 filas (depositos) x 3 columnas (productos).
3. 💰 Reporte Financiero: suma todo el stock de cada producto y calcula cuanto dinero hay invertido.
4. 🔍 Buscar Producto: busca un producto por nombre.

### 💻 Tecnologias que use:
- C++ con structs
- Vectores y matrices bidimensionales
- Funciones separadas, for anidados y switch para el menú
